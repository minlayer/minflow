# @minlayer/minflow

**This is a reserved namespace package. It is not the implementation.**

Install the unscoped package instead:

```bash
npm install minflow
```

This package exists so the `@minlayer` scope mirrors the published package
names, and is held by the [minlayer](https://www.npmjs.com/org/minlayer)
organization. It does not receive functional releases.

- Implementation: [`minflow`](https://www.npmjs.com/package/minflow)
- Source: [github.com/minlayer/minflow](https://github.com/minlayer/minflow)
